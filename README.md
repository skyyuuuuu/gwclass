# 光武國中 701・711 作業成績系統（Firebase 版）

- **老師後台** `teacher.html`：上課進度、作業繳交、作業成績、考試成績、學生總覽、學生名單與登入帳號。
- **家長／學生頁** `student.html`：只看得到自己孩子的繳交狀況、成績、上課進度和全班平均。
- **登入頁** `index.html`：老師用 Email 登入；家長和學生用**學號**加上老師設定的初始密碼登入，**第一次登入一定要先改密碼**才看得到資料。

## 檔案

| 檔案 | 用途 | 部署前要改嗎 |
|---|---|---|
| `js/config.js` | Firebase 設定、老師 UID | **要** |
| `firestore.rules` | 資料庫權限規則（貼到 Firebase 主控台） | **要**（填老師 UID） |
| `index.html`、`teacher.html`、`student.html` | 三個頁面 | 不用 |
| `js/fb.js`、`js/login.js`、`js/teacher.js`、`js/student.js` | 程式 | 不用 |
| `css/style.css` | 樣式 | 不用 |

## 部署步驟（第一次大約 15 分鐘）

### 1. 建立 Firebase 專案
1. 到 <https://console.firebase.google.com> →「建立專案」，名稱例如 `gw-class`。
2. Google Analytics 可以不開。

### 2. 開啟登入功能，建立老師帳號
1. 左側「Authentication」→「開始使用」→「登入方式」→ 啟用 **電子郵件/密碼**（只開第一個開關）。
2. 切到「使用者」→「新增使用者」→ 輸入你自己的 Email 和密碼（這就是老師帳號）。
3. 在使用者清單複製這個帳號的 **使用者 UID**（一串英數字），等一下會用到兩次。

> ⚠️ 不要在 Authentication →「設定」→「使用者動作」裡關閉「啟用建立（註冊）」。老師後台建立學生帳號會用到這個功能。陌生人就算自己註冊帳號，也讀不到任何資料，因為資料庫規則會擋下來。

### 3. 建立資料庫，貼上權限規則
1. 左側「Firestore Database」→「建立資料庫」→ 位置選 **asia-east1（台灣）** →「以正式版模式啟動」。
2. 切到「規則」分頁，把整份 `firestore.rules` 貼上，再把裡面的 `填入老師帳號的 UID` 換成剛剛複製的 UID →「發布」。

### 4. 取得網站設定，填進 `js/config.js`
1. 左上齒輪 →「專案設定」→「一般」→ 最下面「你的應用程式」→ 點 `</>`（網頁）→ 取個暱稱 → 註冊（不用勾 Hosting）。
2. 複製畫面上 `firebaseConfig = { ... }` 的內容，貼到 `js/config.js` 對應的位置。
3. 把 `ADMIN_UID` 也換成你的 UID。

> `apiKey` 放在網頁裡是正常的，Firebase 本來就是這樣設計。真正保護資料的是第 3 步的規則。

### 5. 放上 GitHub Pages
1. 在 GitHub 建立新的 repository，例如 `gw-class`（Public）。
2. 把整個資料夾的檔案上傳，保持原本的資料夾結構（`css/`、`js/`）。
3. repo 的「Settings」→「Pages」→ Source 選「Deploy from a branch」→ Branch 選 `main`、`/ (root)` → Save。
4. 等 1–2 分鐘，網址會是 `https://skyyuuuuu.github.io/gw-class/`。

### 6. 開始使用
1. 打開網址，用老師 Email 登入，系統會自動建立 **701 班、711 班**。
2. 到「學生與帳號」貼上名單（可直接從 Excel 複製「座號、學號、姓名」三欄）。沒有學號的學生，可以之後在名單上補填。
3. 按「為 N 位學生建立帳號」，選擇初始密碼：
   - **每人隨機**（預設，建議）：每位學生的初始密碼都不同。
   - **由我設定**：全班同一組（至少 6 個字元）。比較好發，但知道別人學號的同學就能搶先登入。
4. 畫面會列出「學號＋初始密碼」清單。按 **「列印個別通知單」**，一張 A4 會印 8 張小紙條，每張有學生姓名、登入網址、學號、初始密碼和使用說明。剪開對折後夾進聯絡簿，**不要投影或貼到班群**。清單也可以下載 CSV 留存。家長第一次登入時，會被要求改成自己的密碼。名單上會顯示每位學生是「待首次登入」還是「已啟用」。
5. 之後在「上課進度」「作業」「考試」分頁登記資料，存檔是自動的。

### 7. 舊版網頁的資料搬過來（如果有）
1. 在舊版網頁按右上「備份 ▾」→「匯出備份（JSON）」。
2. 在新後台按「選單 ▾」→「匯入舊版網頁的備份」→ 選那個檔案。
3. 名稱相同、而且還沒有學生的班級會匯入；已經有學生的班級會略過，避免蓋掉新資料。

## 日常操作重點

- **上課進度**：新增時填了「回家作業」，預設會同時加一筆到「作業」登記表（不計分，只登記繳交）。不想加的話，取消勾選即可。
- **先不給家長看**：作業或考試按「編輯」→ 勾「家長看不到這一項」。適合分數還沒登記完的時候用。
- **家長忘記密碼**：在「學生與帳號」按「重設密碼」，設定新的初始密碼（自訂或隨機），舊密碼立刻失效。家長下次登入時一樣要先改密碼。
- **學號打錯**：直接在名單上修改，登入帳號會跟著改，密碼不變。
- **統一初始密碼的提醒**：知道某位學生學號和初始密碼的人，可能搶在本人改密碼之前先登入。發下去後請提醒家長盡快登入；名單上還是「待首次登入」的學生，可以追一下。
- **家長自己改密碼**：家長頁右上角有「改密碼」。家長和學生共用同一組帳號，改了要互相告知。
- **刪除學生**：他的成績紀錄和登入帳號會一起失效。
- **備份**：建議每學期末到「選單」→「下載完整備份（JSON）」，另外也可以匯出 CSV 用 Excel 開。

## 權限設計

| 資料 | 老師 | 家長／學生 |
|---|---|---|
| 班級資訊、作業清單、考試清單、上課進度 | 讀寫 | 只能讀自己班 |
| 每位學生的繳交狀況與分數 | 讀寫 | **只能讀自己** |
| 全班平均（只有平均數字） | 讀寫 | 只能讀自己班 |
| 老師私人備註 | 讀寫 | 讀不到 |
| 自己帳號的「需要改密碼」標記 | 讀寫 | 只能在改完密碼後把它關掉 |
| 其他人自行註冊的帳號 | — | 什麼都讀不到 |

「家長看不到這一項」只是讓那一項不顯示在家長頁。那一項的分數還是存在該生自己的紀錄裡，懂技術的人用瀏覽器開發工具有可能看到自己的分數，但看不到別人的。

## 費用
兩個班的用量遠低於 Firebase 免費方案（Spark）的上限，不需要綁信用卡。

## 常見問題
- **登入後顯示「沒有權限」**：通常是 `firestore.rules` 和 `js/config.js` 裡的 UID 不一樣，或規則沒有按「發布」。
- **建立帳號時出現「嘗試次數太多」**：Firebase 會限制同一個網路短時間內建立太多帳號。等一陣子再按一次「建立帳號」即可，已經建立的不會重複。
- **頁面顯示「尚未完成設定」**：`js/config.js` 還有「填入」的字樣沒改到。
